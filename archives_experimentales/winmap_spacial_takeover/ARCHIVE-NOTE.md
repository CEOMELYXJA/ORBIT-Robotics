# Winmap Spacial Takeover — sources historiques

Cette copie conserve les sources et vérifications du prototype avant son intégration à ORBIT. Pour lancer la version intégrée, utiliser le centre ORBIT dans `integration/`.

L’ancienne version contient des fonctions de connexion et de déplacement de fichiers. Elle est conservée pour référence : ces fonctions sont désactivées dans la copie intégrée. Les images, archives et composants compilés ne sont pas inclus dans cette copie ; les originaux restent à leur emplacement local.
