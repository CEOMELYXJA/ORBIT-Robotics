# Éléments conservés

- Le projet Winmap Spacial Takeover d'origine et ses anciens paquets restent à leur emplacement : ils servent de référence et n'ont pas été remplacés.
- `winmap_host.py` est le premier petit aperçu spatial d'ORBIT. Il reste disponible comme élément historique ; le centre ouvre maintenant l'interface issue de Winmap.
- Les sauvegardes précédentes de l'intégration ORBIT sont conservées sur le Bureau.

La fusion associe le suivi de main ORBIT à une copie locale du visuel Winmap. Le navigateur utilise un profil ORBIT séparé. L'accès aux dossiers réels et les opérations sur leurs fichiers sont désactivés dans cette copie.
